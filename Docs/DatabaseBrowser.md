

# Introduction, Purpose and Scope

The *eiger* SQL database should primarily accessed in your code
through a python API that incorporates the psycopg2 library, as documented [here](https://github.com/rasimcoe/eiger/blob/main/Docs/EIGERDataHandling_r02.pdf), but it is extremely handy
to have a way of running queries interactively in a GUI, and having
the results returned as browsable lists.

This can be done using the free software
[pgadmin4](https://www.pgadmin.org/download/). This is the industry
standard tool used to access postgresql databases, and is well
suported in the community. Installation instructions are included with
the install package, this document explains how to configure pgadmin4
for use with the *eiger* AWS database server, and common ways to run
queries.

For interactive queries the password structure can be somewhat
cumbersome, because we have set up the database using IAM credentials
fom AWS, and these use machine generated passwords that are changed
every 10 minutes.

# Refreshing your AWS IAM credentials 

In the process of configuring the eiger database package, you should have already installed the awstools package. This contains a set of command line tools that you can use to generate new password sets with AWS. The most convenient way to do this is to set up an alias in your .bash_profile or equivalent configuration file, I call this alias "eigerpass" on my system.  Note that this requires your EIGER_DBSERVER environment variable to be set.

> alias eigerpass="aws rds generate-db-auth-token --hostname $EIGERDB_SERVER --port 5432 --region us-east-2 --username $USER | pbcopy" 

In this case, calling "eigerpass" from the command line generates a new password and automatically copies it to your clipboard (like clicking Command-C).

# Configuring **pgadmin4** for use with eiger's AWS database

We assume that your have downloaded and installed the package,
e.g. using the .dmg file for a Mac workstation or laptop. 

Open the application, then select Object->Create->Server, which will open the following window.

<img width="494" alt="CreateServerTab1" src="https://user-images.githubusercontent.com/24480371/161155132-bc21f074-fcef-4c5f-b4f7-f1e6145c3795.png">

Under the "general" tab, give your server any sort of name, this is just a name of conveneince for organizing things locally.  Then go to the "Connection" tab, and enter the following information to configure the server connection, with your approriate aws user name:

<img width="495" alt="CreateServerTab2" src="https://user-images.githubusercontent.com/24480371/161155394-a3254c19-049f-4c64-89d2-a39c9e2f7243.png">

You will see the server appear in the tree view browser to the left.  Right click on this and select "Connect server". Now it will request a password:

<img width="1384" alt="PgadminOpen" src="https://user-images.githubusercontent.com/24480371/161154855-7870ef3a-8d17-4fa3-b207-4746c07e4d9f.png">

At this point, you need to generate a temporary IAM password on the command line.  Go to a terminal and type "eigerpass", then go to the password field and Command-V paste in the secret password generated by the shell script.  

<img width="1384" alt="PastePassword" src="https://user-images.githubusercontent.com/24480371/161155771-333baa4c-1567-4af0-ae1f-3b3dd4aee8ff.png">

If everything worked correctly, you should be connected to the eiger database, and can run raw SQL queries and get back the results in a table format.  To do this, click on the query icon that looks like this: <img width="33" alt="QueryIcon" src="https://user-images.githubusercontent.com/24480371/161156355-65ff61ae-397a-45d8-8a3b-faa4c4863900.png"> and it will generate a Query Editor. 

I've put an example SQL query in this screenshot, "SELECT * FROM Observations" which returns the full Observations table.  Click the "Play" arrow, and the query should run.
